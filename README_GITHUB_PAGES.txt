今日これだけ。— GitHub Pages 友達配布版

最短手順（新しいGitHubリポジトリを使う場合）
1. GitHubで新しいPublic repositoryを作成します。
2. このフォルダ内のファイルをリポジトリのルートへアップロードします。
3. GitHubの Settings → Pages を開きます。
4. Build and deployment → Source で「Deploy from a branch」を選びます。
5. Branch を main、Folder を /(root) にして Save します。
6. 表示された https://<ユーザー名>.github.io/<リポジトリ名>/ をLINEで友達へ送ります。

スマホでは、URLをブラウザで開いたあと「ホーム画面に追加」するとアプリ風に使えます。
データはブラウザ端末内に保存され、端末間で自動同期しません。

注意:
- GitHub FreeでPagesを使う場合、Public repositoryが分かりやすい方法です。
- 公開URLを知っている人はページへアクセスできます。個人情報や秘密情報をリポジトリへ入れないでください。
